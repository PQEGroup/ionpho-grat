# Ion photonics pdk - Look up tables

This directory contains tools for simulating and analyzing 2D optical grating structures. Here we can simulate and analyze fixed period and duty cycle gratings, and also run a sweep to generate a loop up table of grating strength and angle vs period and duty cycle. This lookup table can be used to design focusing/diverging grating couplers. Techniques in this repository follow the paper - [G. J. Beck, J. P. Home and K. K. Mehta, "Grating Design Methodology for Tailored Free-Space Beam-Forming," in Journal of Lightwave Technology, vol. 42, no. 14, pp. 4939-4951, 15 July15, 2024](https://ieeexplore.ieee.org/stamp/stamp.jsp?arnumber=10479983) 

## Getting Started

Files you need to run a simulation -
- A layer stackup json file (see example/alumina_ca.json)
- A csv file containing material index vs wavelength
- Optionally another  csv file containing the index of oxide cladding vs wavelength
- A simulation config file for running a sweep

We can run the simulation just for a single grating period and duty cycle, or for a 2D sweep of periods and duty cycles for multiple wavelengths simultaneously.

### Single 2D grating simulation

1. Set up your material layer stack up in a material JSON file (see `example/alumina_ca.json`)
2. Run a single grating simulation:
   ```bash
   python single_grating_simulation.py --material-file example/alumina_ca.json --csv-file example/alumina_ca.csv --oxide-csv-file example/ox_ca.csv --wavelengths 0.397 0.422
   ```
   For more detailed input arguments, please run
   ```bash
   python single_grating_simulation.py -h
   ```
   and pass the appropriate input arguments
3. Post-process individual simulation results:
   ```bash
   python post_process_2D.py --file path/to/your/results.hdf5
   ```

The plots generated by the post process script give information on - the power decay of the emitted field in Air, the power decay of the field in the waveguide - which gives us the grating strength, the phase of the field in the waveguide from which we get the effective index with a perturbation, the far field emission angle and the fraction of power emitted upwards vs downwards vs undiffracted.

### Look up table genaration through a period/duty cycle sweep
1. Configure your simulation using a JSON config file (see `example/config_example.json`)
2. Or run a parameter sweep:
   ```bash
   python grating_sweep.py --config example/config_example.json --material-file example/alumina_ca.json --csv-file example/alumina_ca.csv --oxide-csv-file example/ox_ca.csv
   ```
   For more detailed input arguments, please run
   ```bash
   python grating_sweep.py -h
   ```
   and pass the appropriate input arguments
3. Post-process sweep results:
   ```bash
   python post_process_sweep.py --config path/to/your/sweep_config.json
   ```
   
2D plots for each wavelength of the grating strength (extracted from the power decay in the waveguide), far field emission angle, fraction of power radiated upwards, effective index vs the swept period and duty cycle.


## Configuration Options

The `example/config_example.json` file demonstrates all available configuration options. Key parameters include:

- Material properties and dispersion data
- Grating geometry (period, duty cycle, waveguide height)
- Simulation settings (runtime, wavelength range, grid resolution)
- Post-processing metrics and visualization options

## File Structure

- `single_grating_simulation.py`: Run a single grating simulation
- `grating_sweep.py`: Run a parameter sweep across multiple values
- `post_process_2D.py`: Process and visualize individual simulation results
- `post_process_sweep.py`: Process and visualize sweep results
- `simulation_helper.py`: Helper functions for setting up simulations
- `material_helper.py`: Functions for handling material properties
- `plot_utils.py`: Visualization functions for simulation results

### Example Files

The `example/` directory contains sample configuration and data files:

- `config_example.json`: Example configuration file for parameter sweeps
- `alumina_ca.json`: Material properties file for alumina
- `alumina_ca.csv`: Dispersion data for alumina
- `ox_ca.csv`: Dispersion data for oxide
- `sin_ca.csv`: Dispersion data for silicon nitride

The examples have values reasonably typical for calcium wavelengths in foundry processes.

## Workflow

1. Use the provided example files as templates (`example/alumina_ca.json`, `example/config_example.json`)
2. Modify the configuration files for your specific simulation parameters
3. Run a single simulation or parameter sweep using the commands shown above
4. Analyze individual results using `post_process_2D.py` or sweep results using `post_process_sweep.py`
5. Review the generated plots and data files in your output directory

## Tips
- The simulation commands will display the appropriate post-processing commands at the end of execution for easy copy/paste usage. 

- There are also regions in the look up table where the grating strength is abnormally high/the effective index is vastly different from the surrounding. This is typically due to interference of the light in the waveguide vs that reflected off the substrate causing a large grating strength. Typically its recommended to look at such points with single simulations to understand whats happening, and if needed, avoid when using the LUT in the grating design process.
