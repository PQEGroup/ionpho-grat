# Ion photonics Grating Design

This codebase implements a modular approach for designing photonics gratings. This uses the look up tables generated by the ion photonics look up tables repository, and takes in a json file with parameters specifying the grating - to actually create the grating in two parts - a longituinal design and transverse design. The code lets us simlate the 2D longitudinal design before proceeding with the transverse design. Techniques in this repository follow the paper - [G. J. Beck, J. P. Home and K. K. Mehta, "Grating Design Methodology for Tailored Free-Space Beam-Forming," in Journal of Lightwave Technology, vol. 42, no. 14, pp. 4939-4951, 15 July15, 2024](https://ieeexplore.ieee.org/stamp/stamp.jsp?arnumber=10479983)

## Running the Code

Run the modular design with:

```bash
python create_grat.py --config path/to/config.json --lut_file path/to/lut_file.mat [options]
```

Command-line arguments:
- `--config CONFIG`: Path to grating configuration file (required)
- `--lut_file LUT_FILE`: Path to LUT file (.mat or .csv format) (required)
- `--show_plots`: Show plots instead of saving them
- `--output_dir OUTPUT_DIR`: Directory to save output files (default: 'output')
- `--sim_config SIM_CONFIG`: Path to simulation configuration JSON file
- `--skip_transverse`: Skip transverse design calculation

Tidy3D simulation options:
- `--run_tidy3d`: Run Tidy3D simulation after design is complete
- `--no_simulation`: Set up Tidy3D simulation but do not run it (only used with --run_tidy3d)
- `--tidy3d_output_dir TIDY3D_OUTPUT_DIR`: Directory to save Tidy3D simulation output (default: {output_dir}/tidy3d)
- `--material_json MATERIAL_JSON`: Path to material stack JSON file (overrides any in sim_config)
Examples:
```bash
# Using .mat LUT file
python create_grat.py --config path/to/config.json --lut_file path/to/matfile.mat --show_plots

# Using .csv LUT file
python create_grat.py --config path/to/config.json --lut_file path/to/sweep_metrics.csv --show_plots

# Skip transverse design (faster execution) - and for testing of just the longitudinal design.
python create_grat.py --config path/to/config.json --lut_file path/to/sweep_metrics.csv --skip_transverse --show_plots
```

To run with Tidy3D simulation:
We can run a 2D FDTD simulation once the longitudinal design is complete, and can visualize the fields generated by the chosen periods/duty cycles. Following this, can proceed with the transverse design to get the grating contour shapes.

```bash
python create_grat.py --config examples/sample_config.json --lut_file path/to/your/lut_file.csv --sim_config examples/sample_sim_config.json --material_json path/to/material_json.json --run_tidy3d --show_plots
```

## Tidy3D Simulation

The package includes functionality to run 2D Tidy3D simulations of the designed gratings. This allows validation of the longitudinal part of the grating design through rigorous electromagnetic simulations. For a full 3D simulation once the whole grating has been desined, please look at the grating simulation repository. These are more expensive simulations compared to a 3D simulation.

To enable Tidy3D simulation, add the `--run_tidy3d` flag when running create_grat.py:

```bash
python create_grat.py --config path/to/config.json --lut_file path/to/lut_file.mat --sim_config examples/sample_sim_config.json --material_json path/to/material_json.json --run_tidy3d
```
The sample_sim_config.json has information about the material indices, and other simulation configurations. The material json used for creating the LUT should also be used here - and it defines the vertical stack of the simulation.

For accurate simulations, you should provide material properties. You have several options:
The simulation will:
1. Create a 2D Tidy3D simulation model of the apodized grating
2. Display the simulation geometry and grating parameters
3. Run the simulation using Tidy3D's web API
4. Analyze the results to calculate coupling efficiency, emission angle, etc.
5. Display visualizations of the electric field and far-field emission pattern

Note: Running Tidy3D simulations requires an account with Flexcompute and Tidy3D.

For testing or previewing the simulation setup without running it, use:
```bash
python create_grat.py --config path/to/config.json --lut_file path/to/lut_file.mat --sim_config examples/sample_sim_config.json --run_tidy3d --no_simulation --material_json path/to/material_stack.json
```

## Configuration

All parameters are stored in a JSON configuration file. To modify the design parameters, simply edit this file rather than changing the code.

Example configuration:
```json
{ 
  "nu": 1.0, # Fraction of power we want radiated out
  "nPts": 2000, # resolution at the grating plane
  "wavelength": 0.397,
  "material": "Alumina",
  "forward_em": 1, # 1 for forward emission, 0 for reverse
  "z0": 20, # ion height
  "useAlphasAir": 0,
  "useGeometricMeanAlpha": 1, # Use an alpha that is geometric mean of that calculated from waveguide and air
  "thetaIncDegrees": 50, # target emission angle
  "w0x": 2.0, # Target longitudinal beam waist at ion height
  "w0y": 1.5, # Target transverse beam waist at ion height
  "zOffx": 0, # Offset focus location of longutudinal waist
  "zOffy": 0, # Offset focus location of transverse waist
  "clipBeginning": 0.85,
  "clipEnd": 1.52,
  "hard_clip": 0,
  "minSize": 0.150, # minimum feature size of process
  "SiSubstrate": 1,
  "tapStart_backEm": -5, # For backward emission grating - location of grating taper start relative to ion position
  "tapStartOffsetBeamCentForward": 35 # For forward emission grating - location of grating taper start relative to center of gaussian beam (sourced from ion location) on grating plane.
}
```

## LUT Files

The Look-Up Table (LUT) files are used to map design parameters to physical properties. The package supports two LUT file formats:

### MATLAB .mat Format

Traditional LUT files in MATLAB .mat format contain pre-computed simulation results for various grating configurations. These files are named according to the following convention:

### CSV Format

CSV LUT files provide a more accessible format for sweep metrics data. These files should contain the following columns:
- `wavelength`: Wavelength in nm
- `period`: Grating period in μm
- `gratDC`: Grating duty cycle
- `pertDC`: Perturbation duty cycle  
- `alpha_wg`: Alpha values in waveguide
- `alpha_air`: Alpha values in air
- `avg_angle_H`: Average H-field angle
- `avg_angle_P`: Average Poynting vector angle
- `n_eff`: Effective index
- `max_peak_angle`: Maximum peak angle (optional)

## Transverse Design

The package includes comprehensive transverse grating design functionality that creates curved grating teeth for optimal beam coupling. The transverse design process:

1. **Phase Analysis**: Extracts phase contours from the combined free-space and waveguide phases
2. **Contour Fitting**: Fits parabolic and quartic curves to the phase contours to determine grating tooth curvature
3. **Parameter Extraction**: Calculates key design parameters including:
   - `r0`: Base radius of curvature
   - `dr`: Differential radius parameter
   - Taper angle and geometry
   - Curved grating tooth coordinates

### Transverse Design Options

- **Default behavior**: Transverse design runs automatically after longitudinal design
- **Skip transverse design**: Use `--skip_transverse` flag for faster execution when only longitudinal design is needed
- **Planar wavefronts**: Configure via the `planar_wavefronts` parameter in the configuration file

### Transverse Design Output

The transverse design generates:
1. **Phase contour plots**: Visualization of phase contours and fitted curves
2. **Coefficient plots**: Display of fitted curve parameters along the grating
3. **Design parameters**: Saved as `transverse_design.npz` containing r0, dr, and taper angle
4. **MATLAB files**: `perDC_interp_initial_*.mat` files for fabrication, including both standard and v7.3 formats

Example usage:
```bash
# Run full design including transverse
python create_grat.py --config config.json --lut_file sweep_metrics.csv

# Skip transverse design for faster execution
python create_grat.py --config config.json --lut_file sweep_metrics.csv --skip_transverse
```

## Output

The code produces:

### Longitudinal Design Output
1. PNG figures showing alpha values, duty cycles, periods, and intensities
2. A .npz file containing design data (waveguide centerline, duty cycles, periods, etc.)

### Transverse Design Output (if not skipped)
3. Phase contour and coefficient plots saved as PNG files
4. `transverse_design.npz` containing transverse design parameters (r0, dr, taper angle)
5. `perDC_interp_initial_*.mat` files for fabrication in both standard and v7.3 MATLAB formats

### Tidy3D Simulation Output

When run with the `--run_tidy3d` flag, the code also produces:
6. HDF5 file containing raw simulation results
7. JSON file with analysis summary (efficiencies, peak angles, etc.)
8. Visualization of the grating structure, electric field, and far-field pattern

## Module Organization

The code has been organized into the following modules:

1. **config_loader.py**: Loads parameters from a JSON file and calculates derived parameters
2. **gaussian_beam.py**: Handles Gaussian beam calculations and transformations
3. **helper_functions.py**: General utility functions used throughout the codebase
4. **beam_propagation.py**: Handles the beam propagation calculations
5. **lut_handler.py**: Loads and processes the look-up tables (LUTs) in both .mat and .csv formats
6. **longitudinal_design.py**: Implements the longitudinal grating design algorithm
7. **transverse_design.py**: Implements transverse grating design with phase analysis and curve fitting
8. **tidy3d_simulation.py**: Creates and runs Tidy3D simulations based on grating designs after the longitudinal design is done.
